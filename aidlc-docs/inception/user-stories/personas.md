# User Personas

## Persona 1: 어드민 — 김수연 (마켓뱅 공동구매 운영자)

| 항목 | 내용 |
|------|------|
| **이름** | 김수연 |
| **역할** | 마켓뱅 공동구매 기획/운영 담당자 |
| **경험** | 와인 유통 3년, 마켓뱅 플랫폼 운영 1년 |
| **목표** | 공구를 빠르게 등록하고, 참여 현황을 실시간으로 파악하며, 마감 처리를 자동화하고 싶음 |
| **불만** | 기존 시스템은 상품 등록이 번거롭고, 상태 관리가 수동이라 실수 발생 가능 |
| **환경** | 데스크톱 (크롬 브라우저), 사무실 근무 |
| **기술 수준** | 중급 (관리 시스템 사용에 익숙, 개발 경험 없음) |

**핵심 니즈:**
- 마켓뱅 상품 URL만 입력하면 정보가 자동으로 채워지길 원함
- 진행 중인 공구의 참여 현황을 한눈에 보고 싶음
- 마감 시 자동 확정/취소로 수동 작업 최소화

## Persona 2: 유저 — 박성진 (와인바 구매 담당자)

| 항목 | 내용 |
|------|------|
| **이름** | 박성진 |
| **역할** | 와인바 'Vin Rouge' 운영자 겸 구매 담당 |
| **경험** | 와인바 운영 5년, 마켓뱅 사용 2년 |
| **목표** | 좋은 와인을 공동구매 가격으로 저렴하게 확보하고 싶음 |
| **동기** | 다른 소매처의 참여 현황을 보고 안심하고 참여 결정을 내림 |
| **불만** | 공구가 성사될지 불확실해서 참여를 망설임, 마감일을 놓침 |
| **환경** | 모바일 우선 (아이폰, 사파리), 매장에서 잠깐 확인 |
| **기술 수준** | 초급-중급 (앱/웹 주문에 익숙, 복잡한 UI는 기피) |

**핵심 니즈:**
- 진행 중인 공구를 빠르게 파악하고 싶음 (가격, 마감, 달성률)
- 다른 사람들이 얼마나 참여했는지 보고 결정하고 싶음 (소셜 증거)
- 간편하게 참여하고, 마음 바뀌면 쉽게 취소하고 싶음
- 공구 확정/취소 결과를 명확히 알고 싶음
